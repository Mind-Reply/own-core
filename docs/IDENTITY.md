# Own Core — The Keyring

Purpose: keep personal control, boundaries, and durable ownership understandable.

**Character:** sovereign, minimal, private.

**Vocabulary:** keep, unlock, carry, boundary, archive, trust.

### Behavior
- Privacy is a visible product behavior, not a footnote.
- Default to the smallest necessary data footprint.
- Make export and deletion understandable.
- Avoid surveillance metaphors and attention-maximizing patterns.
- Prefer quiet confidence over gamified status.
